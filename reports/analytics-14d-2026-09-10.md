## 五、❗关键问题：转化追踪完全失效

**本期最重要的技术发现 —— 需要立即修复。**

### 现状核查

| 项目 | 实测结果 | 含义 |
|---|---|---|
| Vercel Analytics 基础流量统计 | ✅ 正常（59 访客已在面板显示） | 流量测量可信 |
| **Vercel Events（自定义事件）** | ❌ **无数据**，面板提示需升级 Pro | Hobby 计划不支持 Custom Events |
| **GA4（Google Analytics）** | ❌ **线上 HTML 未发现 GA4 脚本** | `NEXT_PUBLIC_GA4_ID` 环境变量**未配置** |
| Clarity | ❌ 未发现脚本 | `NEXT_PUBLIC_CLARITY_ID` 未配置 |

### 为什么会这样

代码中所有转化事件（`inquiry_submit`、`whatsapp_float_click`、`intent_popup_click`、`whatsapp_click`、`intent_popup_shown`）**全部调用 `gtag()`**：

```js
if ((window as any).gtag) {
  (window as any).gtag("event", "inquiry_submit", { ... });
}
```

- `gtag()` 只有在 **GA4 加载后**才存在；GA4 由 `NEXT_PUBLIC_GA4_ID` 环境变量控制，当前未设置 → 脚本不注入 → `gtag` 未定义 → 事件被 `if` 静默跳过，**不报错、不记录**。
- 即使升级 Vercel Pro，这些事件**也不会**出现在 Vercel Events 里 —— Vercel 的自定义事件需要用 `va.track()`（当前代码未使用）。

### 后果

> **59 位访客中，有多少人点了 WhatsApp、填了询盘表单、看了弹窗，目前完全无法得知。**
> 转化率、漏斗、渠道质量（ChatGPT 来的客户 vs Google 来的客户）全部是黑盒。

（说明：此前建议"查看 Vercel Events 的三个事件数"是基于错误假设，特此更正。）
